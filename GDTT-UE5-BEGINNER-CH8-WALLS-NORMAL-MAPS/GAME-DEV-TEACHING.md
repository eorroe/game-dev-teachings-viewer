# GDTT-UE5-BEGINNER-CH8-WALLS-NORMAL-MAPS

## Overview

This chapter teaches how to texture spaceship walls using generated normal maps, mix multiple normal maps together for enhanced surface detail, and use JS Placement to create sci-fi panel textures. You will learn to fix UV stretching in UE5 using the Auto UV feature with the X Atlas method, add emissive lighting driven by height map textures, and control normal map intensity using the Flatten Normal and One-Minus nodes. These techniques let you create highly detailed wall surfaces without needing to model additional geometry.

## When to Follow Game Dev Teachings

- When you need to fix stretched or distorted textures on complex meshes in Unreal Engine
- When working with spaceship or sci-fi environments that require procedural detail generation
- When the user asks about mixing multiple normal maps to add surface detail without extra modeling
- When integrating textures generated by external tools like JS Placement into UE5 materials

## Lessons From Game Dev Teachings

### Lesson 1

#### Examples

##### Example 1: Fixing UV Stretching on Spaceship Walls

When applying a material to a curved or complex mesh, textures appear stretched and distorted in certain areas because the default UV layout does not unfold the surface cleanly.

##### Example 2: Adding Emissive Sci-Fi Lighting via Height Maps

A grayscale height map exported from JS Placement can drive emissive color in a material so that the sci-fi panel patterns glow on the wall surface.

##### Example 3: Mixing Multiple Normal Maps Together

Two separate normal maps (one from the base metal material, one from JS Placement) can be blended together so that the wall reflects light with detail from both sources.

#### Step 1: Fix UV Stretching with Auto UV (X Atlas Method)

With the mesh selected, open the **UVs** tab and choose **Create and Edit UVs**. In the Auto UV panel, try the available methods. Patch Builder and UV Atlas may not produce clean results. Select **X Atlas**, increase the Checker Density as needed to preview the new layout, and optionally adjust Max Iterations. Click **Accept** to apply. The UV stretching on the walls should now be resolved.

#### Step 2: Create a Material Instance to Control Tiling

Right-click the parent material (e.g., Metal_Burnished_Steel) and choose **Create Material Instance**. Open the instance, locate **Base Color** and **Normal Map** inputs, and add a **TextureCoordinate** node driven by an exposed parameter. Connect the tiling parameter into both the base color and normal map UV inputs so that texture repetition is controlled from one slider in the material instance. Experiment with values such as 7, 15, or 50 until the pattern scale looks appropriate.

#### Step 3: Generate Textures with JS Placement

Open JS Placement and generate a sci-fi panel texture using the desired algorithm (e.g., JS Placement Grid or JS Placement 2). Export both the **height map** (grayscale) and the **normal map**. Import both textures into the UE5 Content Browser inside a dedicated folder (e.g., Wall_Textures).

#### Step 4: Add Emissive Lighting from a Height Map

In the material graph, drag the height map texture into the graph. Multiply it by an **RGB** node to control the light color. Multiply the result again by a scalar parameter named **Emissive Intensity** so the brightness is adjustable. Connect the final output to the **Emissive Color** input. Connect the same UV tiling parameter used for the base color into the height map UVs so the emissive pattern matches the rest of the texture.

#### Step 5: Mix Multiple Normal Maps with Blend Angle Corrected Normals

Drag the second normal map (from JS Placement) into the material graph. Add a **Blend Angle Corrected Normals** node. Connect the original base normal map into one input and the JS Placement normal map into the other. Connect the output of the Blend node into the material's **Normal** input. Make sure both normal maps use the same UV tiling parameter so their patterns align.

#### Step 6: Control Normal Map Intensity with Flatten Normal and One-Minus

Add a **Flatten Normal** node between the Blend Angle Corrected Normals output and the material's Normal input. Expose the Flatten value as a scalar parameter called **Normal Intensity**. Note that because Flatten works as a flatness control, a value of 0 gives full intensity and 1 gives no normals (completely flat). To make the parameter behave intuitively (higher value = more intensity), insert a **One-Minus** node between the Normal Intensity parameter and the Flatten Normal input. This inverts the range so that 0 means flat and 1 means full intensity.

#### Best Practices

- ✅ Always match UV tiling across base color, emissive, and normal map layers so patterns stay aligned
- ✅ Save your work before entering modeling or UV editing modes to avoid losing progress
- ✅ Expose tiling, emissive color, emissive intensity, and normal intensity as material instance parameters so artists can iterate quickly
- ✅ Use the X Atlas method in Auto UV when Patch Builder and UV Atlas produce distorted checker patterns
- ✅ Multiply height map emissive output by an RGB node so the light color remains controllable
- ✅ Use Blend Angle Corrected Normals instead of a standard Multiply node when combining two normal maps
- ❌ Do not use a standard Multiply node to blend normal maps together; it produces incorrect results
- ❌ Do not forget to connect the UV tiling parameter to new texture layers, or they will appear at the default scale
- ❌ Do not set the Face Normal Threshold too high when fixing normals in Blender, or beveled edges will stop reflecting light correctly

#### Keep In Mind

- The Auto UV feature works correctly roughly 80% of the time; if X Atlas still produces artifacts, manual UV cleanup may be required
- JS Placement is no longer actively updated by its original developer, but web-based versions and community downloads are still widely available
- A value of 60 for the Blender Face Normal Threshold tends to fix sharp edges while keeping beveled corners smooth; avoid pushing it to 100
- Post Process Volume with Bloom and Glow is needed to make the emissive lights look fully polished; it will be added in a later chapter

#### Security & Safety Notes

- Only download JS Placement from trusted sources listed by the tutorial author or verified community mirrors
- Do not run executables from unverified third-party websites; prefer web-based versions when available
- Keep all scene backups before applying Auto UV or other destructive mesh edits

#### Common Pitfalls

- **Problem:** Textures look stretched or checker patterns are distorted after applying Auto UV  
  **Solution:** Switch from Patch Builder to UV Atlas, then to X Atlas. X Atlas with a moderate Checker Density usually produces the cleanest layout.

- **Problem:** Emissive patterns from the height map appear huge and do not match the rest of the texture  
  **Solution:** Connect the same UV tiling parameter into the height map's UV coordinate input so both layers tile identically.

- **Problem:** Normal map intensity feels backwards when using Flatten Normal  
  **Solution:** Insert a One-Minus node between the exposed parameter and the Flatten Normal input to invert the range so higher values mean more intensity.

- **Problem:** Sharp edges on the mesh still look bad after fixing normals in Blender  
  **Solution:** Re-export the mesh after adjusting the Face Normal Threshold to a value around 60. Values that are too high will prevent proper light reflection on bevels.

- **Problem:** Mixing two normal maps with a standard Multiply node produces dark or incorrect results  
  **Solution:** Use the Blend Angle Corrected Normals node specifically designed for combining two normal map inputs.

## Glossary / Index

|Term|Definition|
|----|----------|
|Auto UV|An Unreal Engine mesh editing feature that automatically generates a new UV layout for a selected mesh to fix stretching and distortion|
|Blend Angle Corrected Normals|A UE5 material node that properly blends two normal map inputs together, preserving correct lighting direction|
|Checker Density|A parameter in Auto UV that controls how tightly the checker preview pattern is packed, helping visualize the quality of the UV layout|
|Emissive Color|A material input in UE5 that makes a surface appear to emit light independent of scene lighting|
|Emissive Intensity|A scalar parameter used to scale the brightness of the emissive color output|
|Face Normal Threshold|A Blender attribute setting that controls how sharp or smooth face normals are blended across edges|
|Flatten Normal|A UE5 material node that controls the intensity of a normal map by flattening it toward a neutral state; lower values mean more detail|
|Height Map|A grayscale texture where brighter values represent higher geometry, used to drive emissive or displacement effects|
|JS Placement|A free external tool that generates sci-fi panel textures, including height maps and normal maps, for use in game engines|
|Material Instance|An instance of a UE5 parent material that allows artists to adjust exposed parameters without modifying the base material|
|Normal Intensity|A scalar parameter controlling how strongly a normal map affects surface lighting|
|Normal Map|A texture that encodes surface detail as RGB vectors, allowing flat geometry to appear to have bumps and grooves|
|One-Minus|A UE5 material math node that inverts a scalar value (output = 1 - input), useful for flipping parameter behavior|
|Patch Builder|An Auto UV layout method in UE5; one of several algorithms available for unfolding mesh UVs|
|Tiling|The repetition scale of a texture across a surface, controlled via a TextureCoordinate parameter in a material instance|
|UV Atlas|An Auto UV layout method in UE5 that packs mesh shells into a texture atlas; may or may not produce clean results depending on the mesh|
|UV Stretching|A visual artifact where textures appear distorted or elongated because the underlying UV layout is not properly unfolded|
|UV Unwrapping|The process of projecting a 3D mesh surface onto a 2D texture space so that textures can be applied cleanly|
|X Atlas|An Auto UV layout method in UE5 that uses the XAtlas algorithm; frequently produces the cleanest UV results for complex meshes|
