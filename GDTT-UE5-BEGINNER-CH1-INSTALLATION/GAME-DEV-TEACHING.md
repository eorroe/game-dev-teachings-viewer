# GDTT-UE5-BEGINNER-CH1-INSTALLATION: Unreal Engine 5 Installation & First Project Setup

## Overview

This game dev teaching walks you through downloading, installing, and setting up Unreal Engine 5 using the Epic Games launcher, then guides you through creating your first blank project named "Star-Wars-final" for building a Star Wars spaceship hangar environment. It covers the launcher interface, engine version management, project template selection, starter content options, and ray tracing considerations to give beginners a solid foundation before diving into 3D environment construction.

## When to Follow Game Dev Teachings

- When you are setting up Unreal Engine 5 for the first time on a new machine
- When you need to install or update the Epic Games launcher and engine versions
- When you are starting a new UE5 project and need to choose the right template and project settings
- When preparing to build cinematic or environment-focused scenes in Unreal Engine
- When the user asks how to create a blank UE5 project for custom 3D world building

## Lessons From Game Dev Teachings

### Lesson 1: Installing Unreal Engine 5 and Creating Your First Project

#### Examples

##### Example 1: Installing the Epic Games Launcher for the First Time

Download the Epic Games launcher from the official Unreal Engine website, run the installer,
create or log in to an Epic Games account, and complete the launcher setup before proceeding
to install any engine version.

##### Example 2: Choosing a Project Template for Cinematic Environment Work

When launching a new project, select the Film/Video/Live Events template as recommended for
beginners working on cinematic or environment-focused scenes, rather than defaulting to
templates optimized for gameplay.

##### Example 3: Creating a Blank Project for a Star Wars Spaceship Hangar

Set up a new blank project named "Star-Wars-final" with the appropriate starter content and
ray tracing settings to begin modeling and assembling a detailed Star Wars hangar environment
inside Unreal Engine 5.

#### Step 1: Download Unreal Engine

Open your web browser and navigate to the official Unreal Engine website. Locate and click
the download link for the Epic Games launcher. Save the installer to your computer and run
it to begin the installation process.

#### Step 2: Install and Set Up the Epic Games Launcher

Run the Epic Games launcher installer. During setup, create a new Epic Games account or log
in with an existing one. Complete the installation and launch the Epic Games launcher to
reach the main dashboard.

#### Step 3: Explore the Epic Games Launcher Interface

Familiarize yourself with the main sections of the Epic Games launcher:
- **News:** Stay updated on engine releases, announcements, and featured content.
- **Samples:** Browse and download free sample projects to learn from.
- **Marketplace:** Discover and acquire assets, plugins, and tools for your projects.
- **Library:** Manage installed engine versions and your project files.

#### Step 4: Select and Install an Engine Version

Go to the Library tab in the Epic Games launcher. If Unreal Engine 5 is not yet installed,
click the "+" button or install option next to the desired engine version. Choose the
appropriate version for your hardware and project needs, then allow the installation to
complete.

#### Step 5: Choose a Project Template

Click the "New Project" or "Launch" button in the launcher to open the project browser.
Browse the available templates. For cinematic, film, video, or environment-focused work,
select the Film/Video/Live Events template as recommended for this tutorial series.

#### Step 6: Configure Starter Content and Ray Tracing Options

Before finalizing project creation, review the project settings. Decide whether to include
Starter Content (pre-built assets and environments useful for learning and prototyping) or
to start with a blank project. Consider enabling or disabling ray tracing based on your
target hardware and performance requirements.

#### Step 7: Create the "Star-Wars-final" Blank Project

Enter "Star-Wars-final" as the project name. Select the desired save location on your
disk. Confirm your template and settings choices, then click "Create" or "Finish" to
generate the new project. Unreal Engine 5 will open the project, and you are now ready
to begin building your Star Wars spaceship hangar environment.

#### Best Practices

- ✅ Download Unreal Engine only from the official Epic Games website to avoid malware.
- ✅ Keep your Epic Games account credentials secure and use a strong password.
- ✅ Choose the Film/Video/Live Events template when working on cinematic or environment scenes.
- ✅ Install the latest stable engine version unless you need specific preview features.
- ✅ Use Starter Content during early learning phases to accelerate prototyping.
- ✅ Enable ray tracing only if your GPU supports it and performance allows.
- ✅ Save projects in a dedicated, well-organized folder structure.
- ❌ Do not share your Epic Games account credentials with others.
- ❌ Do not install Unofficial or pirated copies of Unreal Engine.
- ❌ Do not skip the launcher setup steps; account linking is required for engine access.
- ❌ Avoid creating projects directly in system folders like Program Files or root directories.

#### Keep In Mind

- The Epic Games launcher requires an internet connection for initial setup and engine
  downloads, but Unreal Engine itself can run offline once installed.
- Engine versions can be installed side-by-side, allowing you to switch between projects
  built on different versions.
- Starter Content includes example levels, textures, and materials that are helpful for
  beginners but can increase project file size.
- Ray tracing features (such as Lumen and Nanite) require compatible hardware and may
  impact performance on lower-end systems.
- The "Star-Wars-final" project name should avoid special characters or spaces that may
  cause file path issues.

#### Security & Safety Notes

- Always download the Epic Games launcher from https://www.unrealengine.com to avoid
  malicious software.
- Never enter your Epic Games credentials on third-party websites or unofficial launchers.
- Keep your operating system and GPU drivers up to date to ensure compatibility with
  Unreal Engine 5.
- Be cautious when downloading assets from the Marketplace; review publisher ratings and
  asset permissions before use in commercial projects.
- Regularly back up your project files to avoid data loss during development.

#### Common Pitfalls

- **Problem:** The Epic Games launcher fails to download or install Unreal Engine.
  **Solution:** Ensure you have a stable internet connection, sufficient disk space (at
  least 50-100 GB free), and that your system meets the minimum requirements. Restart the
  launcher or re-run the installer as administrator if issues persist.

- **Problem:** The wrong project template was selected and the project does not fit the
  intended use case.
  **Solution:** You can create a new project with the correct template. Assets can often
  be migrated between projects using Unreal Engine's migration tool if needed.

- **Problem:** Ray tracing causes severe performance drops or crashes.
  **Solution:** Disable ray tracing in project settings or upgrade to a GPU with dedicated
  ray tracing cores (RTX series or AMD RX 7000+). Use the project settings to toggle
  ray tracing features incrementally to identify the cause.

- **Problem:** Project fails to open after creation or shows a black screen.
  **Solution:** Verify that your GPU drivers are up to date. Try launching the project
  directly from the .uproject file. Check the Output Log in the Epic Games launcher for
  error messages.

## Glossary / Index

|Term|Definition|
|----|----------|
|Epic Games Account|A user account required to access the Epic Games launcher, download Unreal Engine, and use the Marketplace.|
|Epic Games Launcher|The official desktop application used to download, install, and manage Unreal Engine versions and projects.|
|Film/Video/Live Events Template|A Unreal Engine project template optimized for cinematic, virtual production, and broadcast workflows.|
|Library|The section of the Epic Games launcher where installed engine versions and user projects are listed and managed.|
|Lumen|Unreal Engine 5's built-in global illumination and reflection system that provides real-time dynamic lighting without baked lightmaps.|
|Marketplace|The Epic Games digital storefront within the launcher for discovering and purchasing assets, plugins, and tools.|
|Nanite|Unreal Engine 5's virtualized geometry technology that enables film-quality assets with billions of polygons to be rendered in real time.|
|News|The Epic Games launcher section that displays engine updates, announcements, and featured content from Epic.|
|Polycam|A mobile and desktop application used to capture 3D scans of real-world objects and environments, often used to import reference assets into Unreal Engine.|
|Project Template|A pre-configured starting point in Unreal Engine that sets up default settings, content, and structure for a specific type of project.|
|Ray Tracing|A rendering technique that simulates the physical behavior of light to produce realistic shadows, reflections, and global illumination in real time.|
|Samples|Free, downloadable example projects provided by Epic Games to help users learn Unreal Engine features and workflows.|
|Starter Content|A collection of pre-built textures, materials, meshes, and example levels included with Unreal Engine for prototyping and learning.|
|Star-Wars-final|The name of the blank project created in this tutorial for building a Star Wars spaceship hangar environment.|
|Unreal Engine 5|A real-time 3D creation tool developed by Epic Games, used for game development, film, architecture, and simulation.|
